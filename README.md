# ShiftFit (시프트 핏)

> 인지적 과부하를 막아주고 빈 시간에 할 일을 자동 배치해 주는 AI 스케줄링 비서

## 📖 기획 문서
자세한 기획 및 제품 요구사항은 [PRD 문서(Product Requirements Document)](./PRD.md)에서 확인하실 수 있습니다.

## ✨ 핵심 기능
- **🎭 페르소나 스위치**: 대학생, 직장인, 개인 시간 등 역할에 따라 모드를 분리하여 인지적 피로도를 줄여줍니다.
- **🧠 AI 브레인 덤프**: 생각나는 대로 입력하면 AI가 알아서 알맞은 카테고리(페르소나)로 자동 분류합니다.
- **🧱 타임 테트리스**: 고정 일정을 제외한 '빈 시간'을 계산하여 할 일을 테트리스처럼 똑똑하게 자동 배치합니다.
- **🛡️ 번아웃 쉴드**: 하루 가용 시간을 초과하는 일정이 생기면, 우선순위가 낮은 일정을 다음 날로 자동 연기하여 번아웃을 예방합니다.

## 🛠️ 기술 스택 (Tech Stack)
- **Frontend / UI**: Next.js (React)
- **Styling**: Tailwind CSS
- **Database**: Neon DB (Serverless PostgreSQL)
- **Deployment**: Vercel
